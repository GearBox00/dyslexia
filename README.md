# すらすら ひらがな

読み書きにつまずいている子ども向けの、ひらがな・カタカナの練習アプリです。

**https://gearbox00.github.io/dyslexia/**

インストール不要。ブラウザで開くだけで動きます。

---

## できること

| モード | 内容 |
|---|---|
| **たたかう** | 下の4つが混ざって出るRPG。負けはなく、敵のHPを削るだけ |
| よむ | お手本の音より先に読めるかを、声のタイミングで見る。もじ / ことば の2段階 |
| かく | 書き順を「みる → なぞる → じぶんで」の3段階で練習(177文字) |
| みわけ | 「わ／ね／れ」「シ／ツ」など、にている形の字を見分ける(17組) |
| おとの かず | 「がっこう」は4拍。特殊音節(ん・っ・ー・拗音)を拍で数える |

## 設計の方針

日本語のディスレクシアは、英語圏とつまずき方が違います。ひらがなは文字と音がほぼ1対1で
対応するため、主な困難は「読めない」ことではなく **「読めるが極端に遅い」** ことです。
そのため、正確さより **速さ・楽に読めること** を鍛える作りにしています。

- **×も失敗音も出しません。** 最大の障壁は失敗体験の積み重ねによる自己肯定感の低下です
- **負けはありません。** 時間はかかっても必ず勝てます
- 純白の背景を避け、**字間・行間を広げて**います
- フォントは **UDデジタル教科書体**(端末にあれば)。読み速度の改善が報告されています
- いわゆる「ディスレクシア専用フォント」は、複数の研究で効果が否定されているため使っていません

## マイクについて

「よむ」では、お手本より先に声を出せたかを判定するためにマイクを使います。

- **音声は端末の外に出ません。** 音量の変化だけを見ており、録音も送信もしません
- 「何と言ったか」は判定していません(音声認識は使っていません)
- マイクを許可しない場合は、自動で画面タップに切り替わります

## 対応環境

Chrome / Edge / Safari の新しめのバージョン。スマホ・タブレットでも動きます。
